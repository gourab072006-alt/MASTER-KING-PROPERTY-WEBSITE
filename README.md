## 🚀 How to Run & Preview

This website is built with zero complex build tooling—pure semantic HTML5, clean modular CSS3, and modern Vanilla JavaScript.

### Option 1: Direct Browser Open
Double-click `index.html` in file explorer or open it in any modern browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python in your terminal:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

Using Node.js (`npx serve`):
```bash
npx serve .
```
